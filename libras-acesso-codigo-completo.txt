# Libras Acesso

Aplicativo web de acessibilidade para pessoas surdas e com deficiência auditiva.

**Recursos:** dicionário de sinais com busca e favoritos, alfabeto e soletração, lições com quiz, cartões de comunicação em tela cheia, legendas ao vivo (fala para texto), alerta visual e por vibração para sons altos, painel de acessibilidade (texto até 200%, alto contraste, tema claro/escuro, menos animação, mais espaçamento) e instalação como app (PWA).

**Tecnologias:** HTML5, CSS3, JavaScript ES6 (módulos), Node.js + Express, MySQL ou Supabase (Postgres), deploy no Render.

## Estrutura

```
frontend/        HTML, CSS e JS do app (sem etapa de build)
backend/
  src/server.js  Servidor Express: API em /api e frontend estático
  src/db/        memory.js, mysql.js e supabase.js (mesma interface)
  sql/           mysql_schema.sql e supabase_schema.sql
  data/          seed.json (conteúdo inicial)
  scripts/       seed.js (carrega o banco) e build.js (gera o protótipo)
  test/          testes automatizados da API
prototype/       libras-acesso-prototipo.html (arquivo único, abre com duplo clique)
render.yaml      Configuração de deploy no Render
```

## Rodar localmente

```bash
cd backend
npm install
cp .env.example .env     # DB_PROVIDER=memory funciona sem banco nenhum
npm start                # http://localhost:3000
npm test
```

O microfone (legendas e alerta de som) exige `https` ou `localhost`.

## Escolher o banco de dados

Defina `DB_PROVIDER` no `.env` (ou no painel do Render):

| Valor | Quando usar | Variáveis |
|---|---|---|
| `memory` | Testes e demonstração. Dados somem ao reiniciar. | nenhuma |
| `supabase` | Produção com Postgres gerenciado. | `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` |
| `mysql` | Produção com MySQL/MariaDB. | `DATABASE_URL` (ou `MYSQL_*`), `MYSQL_SSL` |

### Supabase
1. Crie um projeto em supabase.com.
2. No **SQL Editor**, rode `backend/sql/supabase_schema.sql`.
3. Em **Project Settings > API**, copie a URL e a chave `service_role` para as variáveis.
4. `DB_PROVIDER=supabase npm run seed` carrega os sinais, lições e frases.

A chave `service_role` ignora o RLS. Use apenas no servidor, nunca no frontend nem em repositório público. As tabelas de usuário têm RLS ligado e nenhuma policy, então só o servidor acessa.

### MySQL
1. Crie um banco vazio (utf8mb4).
2. Configure `DATABASE_URL=mysql://usuario:senha@host:3306/banco`.
3. `DB_PROVIDER=mysql npm run seed` cria as tabelas (`sql/mysql_schema.sql`) e carrega o conteúdo.

## Publicar no Render

1. Suba o projeto para um repositório no GitHub.
2. No Render: **New > Blueprint** e escolha o repositório (usa o `render.yaml`).
3. Preencha as variáveis marcadas como secretas no painel.
4. Rode o seed uma vez (pelo seu computador, com as variáveis do banco de produção).
5. O Render usa `/api/health` para verificar o serviço.

No plano gratuito o serviço dorme após inatividade, e a primeira requisição pode demorar. O app continua funcionando com dados locais enquanto isso.

## API

| Método | Rota | Descrição |
|---|---|---|
| GET | `/api/health` | Estado do servidor e do banco |
| GET | `/api/categories` | Categorias |
| GET | `/api/signs?q=&category=&limit=` | Sinais (busca ignora acentos) |
| GET | `/api/signs/:id` | Um sinal |
| GET | `/api/lessons` | Lições |
| GET | `/api/phrases` | Frases dos cartões |
| GET/PUT/DELETE | `/api/users/:userId/favorites[/:signId]` | Favoritos |
| GET/POST | `/api/users/:userId/attempts` | Pontuações de quiz |
| DELETE | `/api/users/:userId` | Apaga os dados do usuário |
| POST | `/api/feedback` | Envia sugestão |

`userId` é um código anônimo (UUID) gerado no aparelho. Não há login nesta versão.

## Antes de publicar de verdade

- **Conteúdo de Libras:** os sinais são exemplos escritos para demonstrar o app. Substitua por vídeos e descrições revisados por intérpretes e pessoas surdas fluentes. Grave a URL em `video_url` e marque `validated = true`. No Supabase, use um bucket público do Storage.
- **Contas de usuário:** o código anônimo não protege dados. Se quiser sincronizar entre aparelhos, adicione login (Supabase Auth) e ajuste as policies de RLS.
- **Alerta de som:** mede só volume e não identifica o tipo de som. Não use como único aviso de segurança.
- **Legendas ao vivo:** usam o reconhecimento de voz do navegador (Chrome/Edge), que pode enviar áudio a um serviço online.
- **Privacidade (LGPD):** informe no app quais dados são guardados e por quê. O botão "Apagar meus dados" já remove favoritos e pontuações.
- **Imagens do alfabeto:** coloque `A.png` a `Z.png` em uma pasta e aponte `ALPHABET_IMAGE_BASE` em `frontend/config.js`.

# Como usar: Render > New > Blueprint > aponte para o repositório.
services:
  - type: web
    name: libras-acesso
    runtime: node
    plan: free
    buildCommand: cd backend && npm install --omit=dev
    startCommand: cd backend && npm start
    healthCheckPath: /api/health
    envVars:
      - key: NODE_VERSION
        value: 20
      - key: NODE_ENV
        value: production
      # memory | mysql | supabase
      - key: DB_PROVIDER
        value: supabase
      # Preencha no painel do Render (sync: false = valor secreto, não vai para o Git)
      - key: SUPABASE_URL
        sync: false
      - key: SUPABASE_SERVICE_ROLE_KEY
        sync: false
      - key: DATABASE_URL
        sync: false
      - key: MYSQL_SSL
        value: "true"
      # Só necessário se o frontend for hospedado em outro domínio
      - key: ALLOWED_ORIGINS
        sync: false

-- Libras Acesso - esquema MySQL 8 / MariaDB 10.5+
-- Idempotente: pode ser executado mais de uma vez.
-- utf8mb4_unicode_ci ignora acentos e maiúsculas nas comparações.

CREATE TABLE IF NOT EXISTS categories (
  id          VARCHAR(40)  NOT NULL,
  name        VARCHAR(80)  NOT NULL,
  icon        VARCHAR(16)  NULL,
  sort_order  INT          NOT NULL DEFAULT 0,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS signs (
  id           VARCHAR(60)  NOT NULL,
  word         VARCHAR(120) NOT NULL,
  category_id  VARCHAR(40)  NOT NULL,
  emoji        VARCHAR(16)  NULL,
  description  TEXT         NOT NULL,
  tip          TEXT         NULL,
  video_url    VARCHAR(500) NULL,
  image_url    VARCHAR(500) NULL,
  validated    TINYINT(1)   NOT NULL DEFAULT 0,
  search_text  TEXT         NOT NULL,
  created_at   TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_signs_category (category_id),
  KEY idx_signs_word (word),
  CONSTRAINT fk_signs_category FOREIGN KEY (category_id) REFERENCES categories (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS lessons (
  id          VARCHAR(60)  NOT NULL,
  title       VARCHAR(120) NOT NULL,
  description TEXT         NULL,
  sort_order  INT          NOT NULL DEFAULT 0,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS lesson_signs (
  lesson_id VARCHAR(60) NOT NULL,
  sign_id   VARCHAR(60) NOT NULL,
  position  INT         NOT NULL DEFAULT 0,
  PRIMARY KEY (lesson_id, sign_id),
  CONSTRAINT fk_ls_lesson FOREIGN KEY (lesson_id) REFERENCES lessons (id) ON DELETE CASCADE,
  CONSTRAINT fk_ls_sign   FOREIGN KEY (sign_id)   REFERENCES signs (id)   ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS phrases (
  id          VARCHAR(60)  NOT NULL,
  text        VARCHAR(300) NOT NULL,
  category    VARCHAR(40)  NOT NULL,
  urgent      TINYINT(1)   NOT NULL DEFAULT 0,
  sort_order  INT          NOT NULL DEFAULT 0,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- user_id é um identificador anônimo gerado no aparelho (UUID).
-- Para contas reais, troque por um id de usuário autenticado.
CREATE TABLE IF NOT EXISTS favorites (
  user_id    VARCHAR(64) NOT NULL,
  sign_id    VARCHAR(60) NOT NULL,
  created_at TIMESTAMP   NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id, sign_id),
  CONSTRAINT fk_fav_sign FOREIGN KEY (sign_id) REFERENCES signs (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS attempts (
  id         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id    VARCHAR(64)  NOT NULL,
  lesson_id  VARCHAR(60)  NOT NULL,
  score      INT          NOT NULL,
  total      INT          NOT NULL,
  created_at TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_attempts_user (user_id, id),
  CONSTRAINT fk_att_lesson FOREIGN KEY (lesson_id) REFERENCES lessons (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS feedback (
  id         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id    VARCHAR(64)  NULL,
  message    TEXT         NOT NULL,
  contact    VARCHAR(200) NULL,
  created_at TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Libras Acesso - esquema para Supabase (Postgres)
-- Cole no SQL Editor do painel do Supabase e execute. É idempotente.

create table if not exists public.categories (
  id         text primary key,
  name       text not null,
  icon       text,
  sort_order int  not null default 0
);

create table if not exists public.signs (
  id          text primary key,
  word        text not null,
  category_id text not null references public.categories (id),
  emoji       text,
  description text not null,
  tip         text,
  video_url   text,
  image_url   text,
  validated   boolean not null default false,
  search_text text not null default '',
  created_at  timestamptz not null default now()
);
create index if not exists idx_signs_category on public.signs (category_id);
create index if not exists idx_signs_word on public.signs (word);

create table if not exists public.lessons (
  id          text primary key,
  title       text not null,
  description text,
  sort_order  int  not null default 0
);

create table if not exists public.lesson_signs (
  lesson_id text not null references public.lessons (id) on delete cascade,
  sign_id   text not null references public.signs (id)   on delete cascade,
  position  int  not null default 0,
  primary key (lesson_id, sign_id)
);

create table if not exists public.phrases (
  id         text primary key,
  text       text not null,
  category   text not null,
  urgent     boolean not null default false,
  sort_order int not null default 0
);

-- Dados de usuário (identificador anônimo gerado no aparelho)
create table if not exists public.favorites (
  user_id    text not null,
  sign_id    text not null references public.signs (id) on delete cascade,
  created_at timestamptz not null default now(),
  primary key (user_id, sign_id)
);

create table if not exists public.attempts (
  id         bigint generated always as identity primary key,
  user_id    text not null,
  lesson_id  text not null references public.lessons (id) on delete cascade,
  score      int  not null,
  total      int  not null,
  created_at timestamptz not null default now()
);
create index if not exists idx_attempts_user on public.attempts (user_id, id desc);

create table if not exists public.feedback (
  id         bigint generated always as identity primary key,
  user_id    text,
  message    text not null,
  contact    text,
  created_at timestamptz not null default now()
);

-- ---------------------------------------------------------------
-- Segurança (RLS)
-- Catálogo: leitura pública. Dados de usuário: nenhuma policy,
-- ou seja, só a service_role (servidor) consegue ler e gravar.
-- ---------------------------------------------------------------
alter table public.categories   enable row level security;
alter table public.signs        enable row level security;
alter table public.lessons      enable row level security;
alter table public.lesson_signs enable row level security;
alter table public.phrases      enable row level security;
alter table public.favorites    enable row level security;
alter table public.attempts     enable row level security;
alter table public.feedback     enable row level security;

drop policy if exists "catalogo publico" on public.categories;
drop policy if exists "catalogo publico" on public.signs;
drop policy if exists "catalogo publico" on public.lessons;
drop policy if exists "catalogo publico" on public.lesson_signs;
drop policy if exists "catalogo publico" on public.phrases;

create policy "catalogo publico" on public.categories   for select using (true);
create policy "catalogo publico" on public.signs        for select using (true);
create policy "catalogo publico" on public.lessons      for select using (true);
create policy "catalogo publico" on public.lesson_signs for select using (true);
create policy "catalogo publico" on public.phrases      for select using (true);

// ARQUIVO: backend/data/seed.js
================================================================
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const here = path.dirname(fileURLToPath(import.meta.url));

/** Remove acentos e deixa em minúsculas, para busca que ignora acentuação. */
export function normalize(text) {
  return String(text ?? '')
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .trim();
}

/** Lê o seed.json e calcula o campo de busca de cada sinal. */
export function loadSeed() {
  const raw = JSON.parse(readFileSync(path.join(here, 'seed.json'), 'utf8'));
  const categoryName = new Map(raw.categories.map((c) => [c.id, c.name]));
  const signs = raw.signs.map((s) => ({
    ...s,
    searchText: normalize(`${s.word} ${s.description} ${categoryName.get(s.category) ?? ''}`)
  }));
  return { ...raw, signs };
}

import 'dotenv/config';
import express from 'express';
import cors from 'cors';
import helmet from 'helmet';
import rateLimit from 'express-rate-limit';
import path from 'node:path';
import { existsSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { createRepository } from './db/index.js';
import { buildRouter, HttpError } from './routes.js';

const here = path.dirname(fileURLToPath(import.meta.url));
const FRONTEND_DIR = path.resolve(here, '../../frontend');

export async function createApp(env = process.env) {
  const repo = await createRepository(env);
  const app = express();

  // Atrás do proxy do Render: necessário para o rate limit enxergar o IP real.
  app.set('trust proxy', 1);
  app.disable('x-powered-by');

  app.use(
    helmet({
      contentSecurityPolicy: {
        directives: {
          defaultSrc: ["'self'"],
          scriptSrc: ["'self'"],
          styleSrc: ["'self'", "'unsafe-inline'"],
          imgSrc: ["'self'", 'data:', 'https:'],
          mediaSrc: ["'self'", 'https:'],
          connectSrc: ["'self'"],
          objectSrc: ["'none'"],
          baseUri: ["'self'"],
          frameAncestors: ["'self'"]
        }
      },
      // O microfone é usado pelas legendas ao vivo e pelo alerta de som.
      crossOriginEmbedderPolicy: false
    })
  );
  app.use((_req, res, next) => {
    res.setHeader('Permissions-Policy', 'microphone=(self), geolocation=(), camera=()');
    next();
  });

  const allowed = (env.ALLOWED_ORIGINS || '')
    .split(',')
    .map((s) => s.trim())
    .filter(Boolean);
  app.use(
    '/api',
    cors({
      origin: allowed.length ? allowed : env.NODE_ENV === 'production' ? false : true,
      methods: ['GET', 'POST', 'PUT', 'DELETE'],
      maxAge: 600
    })
  );

  app.use(express.json({ limit: '20kb' }));
  app.use(
    '/api',
    rateLimit({ windowMs: 60 * 1000, limit: 120, standardHeaders: 'draft-7', legacyHeaders: false, message: { error: 'Muitas requisições. Aguarde um instante.' } })
  );

  app.use('/api', buildRouter(repo));
  app.use('/api', (_req, res) => res.status(404).json({ error: 'Rota não encontrada.' }));

  // Frontend estático (mesmo serviço no Render)
  if (existsSync(FRONTEND_DIR)) {
    app.use(express.static(FRONTEND_DIR, { extensions: ['html'], maxAge: env.NODE_ENV === 'production' ? '1h' : 0 }));
  }

  // eslint-disable-next-line no-unused-vars
  app.use((err, _req, res, _next) => {
    if (err?.type === 'entity.parse.failed') return res.status(400).json({ error: 'JSON inválido.' });
    if (err instanceof HttpError) return res.status(err.status).json({ error: err.message, details: err.details });
    console.error(err);
    res.status(500).json({ error: 'Erro interno do servidor.' });
  });

  return { app, repo };
}

// Só inicia o servidor quando o arquivo é executado diretamente (não nos testes).
if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const port = Number(process.env.PORT || 3000);
  const { app, repo } = await createApp();
  app.listen(port, () => {
    console.log(`Libras Acesso rodando em http://localhost:${port} (banco: ${repo.provider})`);
  });
}

import { Router } from 'express';
import rateLimit from 'express-rate-limit';
import { z } from 'zod';

const asyncHandler = (fn) => (req, res, next) => Promise.resolve(fn(req, res, next)).catch(next);

// Identificadores: letras, números e hífen (UUID, slugs dos sinais etc.)
const userIdSchema = z.string().regex(/^[a-zA-Z0-9-]{8,64}$/, 'Identificador de usuário inválido.');
const slugSchema = z.string().regex(/^[a-z0-9-]{1,60}$/, 'Identificador inválido.');

const attemptSchema = z
  .object({
    lessonId: slugSchema,
    score: z.number().int().min(0).max(100),
    total: z.number().int().min(1).max(100)
  })
  .refine((a) => a.score <= a.total, { message: 'A pontuação não pode ser maior que o total.' });

const feedbackSchema = z.object({
  userId: userIdSchema.optional(),
  message: z.string().trim().min(3, 'Escreva uma mensagem.').max(1000, 'Mensagem muito longa (máx. 1000 caracteres).'),
  contact: z.string().trim().max(200).optional()
});

const signsQuerySchema = z.object({
  q: z.string().trim().max(80).optional(),
  category: slugSchema.optional(),
  limit: z.coerce.number().int().min(1).max(500).optional()
});

class HttpError extends Error {
  constructor(status, message, details) {
    super(message);
    this.status = status;
    this.details = details;
  }
}

function parse(schema, value) {
  const result = schema.safeParse(value);
  if (!result.success) {
    const details = result.error.issues.map((i) => i.message);
    throw new HttpError(400, details[0] ?? 'Dados inválidos.', details);
  }
  return result.data;
}

export function buildRouter(repo) {
  const router = Router();

  const feedbackLimiter = rateLimit({
    windowMs: 60 * 60 * 1000,
    limit: 10,
    standardHeaders: 'draft-7',
    legacyHeaders: false,
    message: { error: 'Muitos envios. Tente novamente mais tarde.' }
  });

  router.get(
    '/health',
    asyncHandler(async (_req, res) => {
      let database = 'ok';
      try {
        await repo.ping();
      } catch {
        database = 'erro';
      }
      res.status(database === 'ok' ? 200 : 503).json({ status: database === 'ok' ? 'ok' : 'degradado', provider: repo.provider, database });
    })
  );

  router.get('/categories', asyncHandler(async (_req, res) => res.json(await repo.listCategories())));

  router.get(
    '/signs',
    asyncHandler(async (req, res) => {
      const query = parse(signsQuerySchema, req.query);
      res.json(await repo.listSigns(query));
    })
  );

  router.get(
    '/signs/:id',
    asyncHandler(async (req, res) => {
      const id = parse(slugSchema, req.params.id);
      const sign = await repo.getSign(id);
      if (!sign) throw new HttpError(404, 'Sinal não encontrado.');
      res.json(sign);
    })
  );

  router.get('/lessons', asyncHandler(async (_req, res) => res.json(await repo.listLessons())));
  router.get('/phrases', asyncHandler(async (_req, res) => res.json(await repo.listPhrases())));

  // --- Dados do usuário (identificador anônimo) -----------------
  router.get(
    '/users/:userId/favorites',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      res.json(await repo.listFavorites(userId));
    })
  );

  router.put(
    '/users/:userId/favorites/:signId',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      const signId = parse(slugSchema, req.params.signId);
      if (!(await repo.getSign(signId))) throw new HttpError(404, 'Sinal não encontrado.');
      await repo.addFavorite(userId, signId);
      res.status(204).end();
    })
  );

  router.delete(
    '/users/:userId/favorites/:signId',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      const signId = parse(slugSchema, req.params.signId);
      await repo.removeFavorite(userId, signId);
      res.status(204).end();
    })
  );

  router.get(
    '/users/:userId/attempts',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      res.json(await repo.listAttempts(userId));
    })
  );

  router.post(
    '/users/:userId/attempts',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      const attempt = parse(attemptSchema, req.body);
      const lessons = await repo.listLessons();
      if (!lessons.some((l) => l.id === attempt.lessonId)) throw new HttpError(404, 'Lição não encontrada.');
      await repo.saveAttempt(userId, attempt);
      res.status(201).json({ ok: true });
    })
  );

  // Direito de exclusão (LGPD): apaga favoritos e pontuações do código anônimo.
  router.delete(
    '/users/:userId',
    asyncHandler(async (req, res) => {
      const userId = parse(userIdSchema, req.params.userId);
      await repo.deleteUserData(userId);
      res.status(204).end();
    })
  );

  router.post(
    '/feedback',
    feedbackLimiter,
    asyncHandler(async (req, res) => {
      const data = parse(feedbackSchema, req.body);
      await repo.addFeedback(data);
      res.status(201).json({ ok: true });
    })
  );

  return router;
}

export { HttpError };

/**
 * Escolhe o repositório de dados conforme DB_PROVIDER.
 * Todos os repositórios expõem a mesma interface assíncrona:
 *
 *   ping(), listCategories(), listSigns({ q, category, limit }), getSign(id),
 *   listLessons(), listPhrases(),
 *   listFavorites(userId), addFavorite(userId, signId), removeFavorite(userId, signId),
 *   listAttempts(userId), saveAttempt(userId, { lessonId, score, total }),
 *   addFeedback({ userId, message, contact }), seed(data)
 */
export async function createRepository(env = process.env) {
  const provider = (env.DB_PROVIDER || 'memory').toLowerCase();

  switch (provider) {
    case 'memory': {
      const { MemoryRepository } = await import('./memory.js');
      return new MemoryRepository();
    }
    case 'mysql': {
      const { MySqlRepository } = await import('./mysql.js');
      return new MySqlRepository(env);
    }
    case 'supabase': {
      const { SupabaseRepository } = await import('./supabase.js');
      return new SupabaseRepository(env);
    }
    default:
      throw new Error(`DB_PROVIDER inválido: "${provider}". Use memory, mysql ou supabase.`);
  }
}

import { loadSeed, normalize } from '../../data/seed.js';

const publicSign = ({ searchText, ...sign }) => sign;

/** Repositório em memória: ótimo para desenvolvimento e testes. Os dados somem ao reiniciar. */
export class MemoryRepository {
  provider = 'memory';

  constructor() {
    this.data = loadSeed();
    this.favorites = new Map(); // userId -> Set(signId)
    this.attempts = []; // { userId, lessonId, score, total, createdAt }
    this.feedback = [];
  }

  async ping() {
    return true;
  }

  async listCategories() {
    return [...this.data.categories].sort((a, b) => a.sortOrder - b.sortOrder).map(({ sortOrder, ...c }) => c);
  }

  async listSigns({ q, category, limit = 200 } = {}) {
    const term = normalize(q);
    return this.data.signs
      .filter((s) => (!category || s.category === category) && (!term || s.searchText.includes(term)))
      .sort((a, b) => a.word.localeCompare(b.word, 'pt-BR'))
      .slice(0, limit)
      .map(publicSign);
  }

  async getSign(id) {
    const sign = this.data.signs.find((s) => s.id === id);
    return sign ? publicSign(sign) : null;
  }

  async listLessons() {
    return [...this.data.lessons].sort((a, b) => a.sortOrder - b.sortOrder).map(({ sortOrder, ...l }) => l);
  }

  async listPhrases() {
    return this.data.phrases;
  }

  async listFavorites(userId) {
    return [...(this.favorites.get(userId) ?? [])];
  }

  async addFavorite(userId, signId) {
    if (!this.favorites.has(userId)) this.favorites.set(userId, new Set());
    this.favorites.get(userId).add(signId);
  }

  async removeFavorite(userId, signId) {
    this.favorites.get(userId)?.delete(signId);
  }

  async listAttempts(userId) {
    return this.attempts
      .filter((a) => a.userId === userId)
      .slice(-100)
      .reverse()
      .map(({ userId: _u, ...a }) => a);
  }

  async saveAttempt(userId, { lessonId, score, total }) {
    this.attempts.push({ userId, lessonId, score, total, createdAt: new Date().toISOString() });
  }

  async deleteUserData(userId) {
    this.favorites.delete(userId);
    this.attempts = this.attempts.filter((a) => a.userId !== userId);
  }

  async addFeedback({ userId, message, contact }) {
    this.feedback.push({ userId, message, contact, createdAt: new Date().toISOString() });
  }

  async seed() {
    this.data = loadSeed();
  }
}

    cfg = {
      host: env.MYSQL_HOST,
      port: Number(env.MYSQL_PORT || 3306),
      user: env.MYSQL_USER,
      password: env.MYSQL_PASSWORD,
      database: env.MYSQL_DATABASE
    };
  }
  if (!cfg.host || !cfg.user || !cfg.database) {
    throw new Error('MySQL não configurado: defina DATABASE_URL ou MYSQL_HOST/MYSQL_USER/MYSQL_DATABASE.');
  }
  return {
    ...cfg,
    charset: 'utf8mb4',
    ...(String(env.MYSQL_SSL).toLowerCase() === 'true' ? { ssl: { rejectUnauthorized: true } } : {})
  };
}

const SIGN_COLUMNS = `id, word, category_id AS category, emoji, description, tip,
  video_url AS videoUrl, image_url AS imageUrl, validated`;

const toSign = (row) => ({ ...row, validated: Boolean(row.validated) });

export class MySqlRepository {
  provider = 'mysql';

  constructor(env) {
    this.config = buildConfig(env);
    this.pool = mysql.createPool({
      ...this.config,
      waitForConnections: true,
      connectionLimit: 10,
      queueLimit: 0
    });
  }

  async ping() {
    await this.pool.query('SELECT 1');
    return true;
  }

  /** Cria as tabelas (idempotente). Usado pelo script de seed. */
  async migrate() {
    const sql = await readFile(SCHEMA_FILE, 'utf8');
    const conn = await mysql.createConnection({ ...this.config, multipleStatements: true });
    try {
      await conn.query(sql);
    } finally {
      await conn.end();
    }
  }

  async listCategories() {
    const [rows] = await this.pool.query('SELECT id, name, icon FROM categories ORDER BY sort_order');
    return rows;
  }

  async listSigns({ q, category, limit = 200 } = {}) {
    const where = [];
    const params = [];
    if (category) {
      where.push('category_id = ?');
      params.push(category);
    }
    const term = normalize(q);
    if (term) {
      where.push('search_text LIKE ?');
      params.push(`%${escapeLike(term)}%`);
    }
    const sql = `SELECT ${SIGN_COLUMNS} FROM signs ${where.length ? `WHERE ${where.join(' AND ')}` : ''}
                 ORDER BY word LIMIT ?`;
    const [rows] = await this.pool.query(sql, [...params, Number(limit)]);
    return rows.map(toSign);
  }

  async getSign(id) {
    const [rows] = await this.pool.query(`SELECT ${SIGN_COLUMNS} FROM signs WHERE id = ? LIMIT 1`, [id]);
    return rows[0] ? toSign(rows[0]) : null;
  }

  async listLessons() {
    const [lessons] = await this.pool.query('SELECT id, title, description FROM lessons ORDER BY sort_order');
    const [links] = await this.pool.query('SELECT lesson_id, sign_id FROM lesson_signs ORDER BY lesson_id, position');
    const byLesson = new Map();
    for (const { lesson_id, sign_id } of links) {
      if (!byLesson.has(lesson_id)) byLesson.set(lesson_id, []);
      byLesson.get(lesson_id).push(sign_id);
    }
    return lessons.map((l) => ({ ...l, signIds: byLesson.get(l.id) ?? [] }));
  }

  async listPhrases() {
    const [rows] = await this.pool.query('SELECT id, text, category, urgent FROM phrases ORDER BY sort_order');
    return rows.map((r) => ({ ...r, urgent: Boolean(r.urgent) }));
  }

  async listFavorites(userId) {
    const [rows] = await this.pool.query('SELECT sign_id FROM favorites WHERE user_id = ? ORDER BY created_at', [userId]);
    return rows.map((r) => r.sign_id);
  }

  async addFavorite(userId, signId) {
    await this.pool.query('INSERT IGNORE INTO favorites (user_id, sign_id) VALUES (?, ?)', [userId, signId]);
  }

  async removeFavorite(userId, signId) {
    await this.pool.query('DELETE FROM favorites WHERE user_id = ? AND sign_id = ?', [userId, signId]);
  }

  async listAttempts(userId) {
    const [rows] = await this.pool.query(
      `SELECT lesson_id AS lessonId, score, total, created_at AS createdAt
       FROM attempts WHERE user_id = ? ORDER BY id DESC LIMIT 100`,
      [userId]
    );
    return rows.map((r) => ({ ...r, createdAt: new Date(r.createdAt).toISOString() }));
  }

  async saveAttempt(userId, { lessonId, score, total }) {
    await this.pool.query('INSERT INTO attempts (user_id, lesson_id, score, total) VALUES (?, ?, ?, ?)', [
      userId,
      lessonId,
      score,
      total
    ]);
  }

  async deleteUserData(userId) {
    await this.pool.query('DELETE FROM favorites WHERE user_id = ?', [userId]);
    await this.pool.query('DELETE FROM attempts WHERE user_id = ?', [userId]);
  }

  async addFeedback({ userId, message, contact }) {
    await this.pool.query('INSERT INTO feedback (user_id, message, contact) VALUES (?, ?, ?)', [
      userId ?? null,
      message,
      contact ?? null
    ]);
  }

  /** Carrega o conteúdo inicial (categorias, sinais, lições e frases). */
  async seed(data) {
    const conn = await this.pool.getConnection();
    try {
      await conn.beginTransaction();

      await conn.query(
        `INSERT INTO categories (id, name, icon, sort_order) VALUES ?
         ON DUPLICATE KEY UPDATE name = VALUES(name), icon = VALUES(icon), sort_order = VALUES(sort_order)`,
        [data.categories.map((c) => [c.id, c.name, c.icon, c.sortOrder])]
      );

      await conn.query(
        `INSERT INTO signs (id, word, category_id, emoji, description, tip, video_url, image_url, validated, search_text) VALUES ?
         ON DUPLICATE KEY UPDATE word = VALUES(word), category_id = VALUES(category_id), emoji = VALUES(emoji),
           description = VALUES(description), tip = VALUES(tip), search_text = VALUES(search_text)`,
        [data.signs.map((s) => [s.id, s.word, s.category, s.emoji, s.description, s.tip, s.videoUrl, s.imageUrl, s.validated ? 1 : 0, s.searchText])]
      );

      await conn.query(
        `INSERT INTO lessons (id, title, description, sort_order) VALUES ?
         ON DUPLICATE KEY UPDATE title = VALUES(title), description = VALUES(description), sort_order = VALUES(sort_order)`,
        [data.lessons.map((l) => [l.id, l.title, l.description, l.sortOrder])]
      );

      await conn.query('DELETE FROM lesson_signs');
      const links = data.lessons.flatMap((l) => l.signIds.map((signId, i) => [l.id, signId, i + 1]));
      await conn.query('INSERT INTO lesson_signs (lesson_id, sign_id, position) VALUES ?', [links]);

      await conn.query(
        `INSERT INTO phrases (id, text, category, urgent, sort_order) VALUES ?
         ON DUPLICATE KEY UPDATE text = VALUES(text), category = VALUES(category), urgent = VALUES(urgent), sort_order = VALUES(sort_order)`,
        [data.phrases.map((p, i) => [p.id, p.text, p.category, p.urgent ? 1 : 0, i + 1])]
      );

      await conn.commit();
    } catch (err) {
      await conn.rollback();
      throw err;
    } finally {
      conn.release();
    }
  }
}

import { createClient } from '@supabase/supabase-js';
import { normalize } from '../../data/seed.js';

const SIGN_COLUMNS = 'id, word, category_id, emoji, description, tip, video_url, image_url, validated';

const toSign = (row) => ({
  id: row.id,
  word: row.word,
  category: row.category_id,
  emoji: row.emoji,
  description: row.description,
  tip: row.tip,
  videoUrl: row.video_url,
  imageUrl: row.image_url,
  validated: Boolean(row.validated)
});

/** Remove caracteres com significado especial em filtros do PostgREST e curingas do LIKE. */
const sanitizeTerm = (text) => normalize(text).replace(/[%_*,()\\"']/g, ' ').replace(/\s+/g, ' ').trim();

function check({ data, error }) {
  if (error) throw new Error(`Supabase: ${error.message}`);
  return data;
}

/**
 * Repositório Supabase (Postgres). Usa a service_role key, portanto roda só no servidor.
 * As tabelas de usuário (favorites, attempts, feedback) têm RLS ligado e nenhuma policy pública:
 * só o servidor consegue lê-las ou gravá-las.
 */
export class SupabaseRepository {
  provider = 'supabase';

  constructor(env) {
    if (!env.SUPABASE_URL || !env.SUPABASE_SERVICE_ROLE_KEY) {
      throw new Error('Supabase não configurado: defina SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY.');
    }
    this.db = createClient(env.SUPABASE_URL, env.SUPABASE_SERVICE_ROLE_KEY, {
      auth: { persistSession: false, autoRefreshToken: false }
    });
  }

  async ping() {
    check(await this.db.from('categories').select('id').limit(1));
    return true;
  }

  async listCategories() {
    return check(await this.db.from('categories').select('id, name, icon').order('sort_order'));
  }

  async listSigns({ q, category, limit = 200 } = {}) {
    let query = this.db.from('signs').select(SIGN_COLUMNS).order('word').limit(Number(limit));
    if (category) query = query.eq('category_id', category);
    const term = sanitizeTerm(q);
    if (term) query = query.ilike('search_text', `%${term}%`);
    return check(await query).map(toSign);
  }

  async getSign(id) {
    const row = check(await this.db.from('signs').select(SIGN_COLUMNS).eq('id', id).maybeSingle());
    return row ? toSign(row) : null;
  }

  async listLessons() {
    const rows = check(
      await this.db.from('lessons').select('id, title, description, sort_order, lesson_signs(sign_id, position)').order('sort_order')
    );
    return rows.map((l) => ({
      id: l.id,
      title: l.title,
      description: l.description,
      signIds: [...l.lesson_signs].sort((a, b) => a.position - b.position).map((x) => x.sign_id)
    }));
  }

  async listPhrases() {
    return check(await this.db.from('phrases').select('id, text, category, urgent').order('sort_order'));
  }

  async listFavorites(userId) {
    const rows = check(await this.db.from('favorites').select('sign_id').eq('user_id', userId).order('created_at'));
    return rows.map((r) => r.sign_id);
  }

  async addFavorite(userId, signId) {
    check(
      await this.db
        .from('favorites')
        .upsert({ user_id: userId, sign_id: signId }, { onConflict: 'user_id,sign_id', ignoreDuplicates: true })
    );
  }

  async removeFavorite(userId, signId) {
    check(await this.db.from('favorites').delete().eq('user_id', userId).eq('sign_id', signId));
  }

  async listAttempts(userId) {
    const rows = check(
      await this.db
        .from('attempts')
        .select('lesson_id, score, total, created_at')
        .eq('user_id', userId)
        .order('id', { ascending: false })
        .limit(100)
    );
    return rows.map((r) => ({ lessonId: r.lesson_id, score: r.score, total: r.total, createdAt: r.created_at }));
  }

  async saveAttempt(userId, { lessonId, score, total }) {
    check(await this.db.from('attempts').insert({ user_id: userId, lesson_id: lessonId, score, total }));
  }

  async deleteUserData(userId) {
    check(await this.db.from('favorites').delete().eq('user_id', userId));
    check(await this.db.from('attempts').delete().eq('user_id', userId));
  }

  async addFeedback({ userId, message, contact }) {
    check(await this.db.from('feedback').insert({ user_id: userId ?? null, message, contact: contact ?? null }));
  }

  /** Carrega o conteúdo inicial. As tabelas precisam existir (rode sql/supabase_schema.sql antes). */
  async seed(data) {
    check(
      await this.db
        .from('categories')
        .upsert(data.categories.map((c) => ({ id: c.id, name: c.name, icon: c.icon, sort_order: c.sortOrder })))
    );

    check(
      await this.db.from('signs').upsert(
        data.signs.map((s) => ({
          id: s.id,
          word: s.word,
          category_id: s.category,
          emoji: s.emoji,
          description: s.description,
          tip: s.tip,
          video_url: s.videoUrl,
          image_url: s.imageUrl,
          validated: s.validated,
          search_text: s.searchText
        }))
      )
    );

    check(
      await this.db
        .from('lessons')
        .upsert(data.lessons.map((l) => ({ id: l.id, title: l.title, description: l.description, sort_order: l.sortOrder })))
    );

    check(await this.db.from('lesson_signs').delete().neq('lesson_id', ''));
    const links = data.lessons.flatMap((l) => l.signIds.map((signId, i) => ({ lesson_id: l.id, sign_id: signId, position: i + 1 })));
    check(await this.db.from('lesson_signs').insert(links));

    check(
      await this.db
        .from('phrases')
        .upsert(data.phrases.map((p, i) => ({ id: p.id, text: p.text, category: p.category, urgent: p.urgent, sort_order: i + 1 })))
    );
  }
}

  .map((name) => {
    let source = read('js', `${name}.js`);
    source = source.replace(/^import[\s\S]*?from\s+['"][^'"]+['"];?[ \t]*$/gm, '');
    source = source.replace(/^export\s+(?=(const|let|function|async function|class)\b)/gm, '');

      topLevelNames.set(match[1], `${name}.js`);
    }
    if (/^\s*(import|export)\s/m.test(source)) throw new Error(`Sobrou import/export em ${name}.js`);
    return `// ---- ${name}.js ----\n${source}`;

// Service worker: guarda os arquivos do app para abrir offline.
// A API não é guardada aqui; o app já tem dados de exemplo e salva favoritos/pontuação no aparelho.
const CACHE = 'libras-acesso-v1';
const ASSETS = [
  './', 'index.html', 'config.js', 'manifest.webmanifest', 'icon.svg', 'css/styles.css',
  'js/app.js', 'js/storage.js', 'js/ui.js', 'js/data.js', 'js/api.js', 'js/state.js', 'js/a11y.js',
  'js/router.js', 'js/dictionary.js', 'js/alphabet.js', 'js/learn.js', 'js/communicate.js',
  'js/captions.js', 'js/soundalert.js', 'js/progress.js'
];

self.addEventListener('install', (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(ASSETS)).then(() => self.skipWaiting()));
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys()
      .then((keys) => Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))))
      .then(() => self.clients.claim())
  );
});

self.addEventListener('fetch', (event) => {
  const { request } = event;
  const url = new URL(request.url);
  if (request.method !== 'GET' || url.origin !== self.location.origin || url.pathname.startsWith('/api/')) return;

  // Rede primeiro (conteúdo sempre atualizado), cache como reserva offline.
  event.respondWith(
    fetch(request)
      .then((response) => {
        const copy = response.clone();
        caches.open(CACHE).then((cache) => cache.put(request, copy));
        return response;
      })
      .catch(() => caches.match(request).then((hit) => hit || caches.match('index.html')))
  );
});

import { $, openDialog, wireDialog } from './ui.js';
import { storage } from './storage.js';

const DEFAULT_SETTINGS = { fontScale: 100, theme: 'auto', contrast: false, motion: false, spacing: false, flash: true, vibrate: true };
export const settings = { ...DEFAULT_SETTINGS, ...storage.get('settings', {}) };

let themeApplied = false;

function applySettings() {
  const root = document.documentElement;
  root.style.setProperty('--fs', String(settings.fontScale / 100));

  // Só mexe no tema se a pessoa escolheu um (ou se fomos nós que o definimos antes).
  if (settings.theme !== 'auto') {
    root.setAttribute('data-theme', settings.theme);
    themeApplied = true;
  } else if (themeApplied) {
    root.removeAttribute('data-theme');
    themeApplied = false;
  }

  root.dataset.contrast = settings.contrast ? 'high' : 'normal';
  root.dataset.motion = settings.motion ? 'reduce' : 'normal';
  root.dataset.spacing = settings.spacing ? 'wide' : 'normal';
  root.dataset.flash = settings.flash ? 'on' : 'off';

import { $, el, normalize, debounce } from './ui.js';
import { on } from './state.js';

const LETTERS = [...'ABCDEFGHIJKLMNOPQRSTUVWXYZ'];

// Emojis que lembram a forma da mão, só para letras em que a semelhança é clara.
// São aproximações: o emoji não reproduz o sinal oficial. Para imagens oficiais, use ALPHABET_IMAGE_BASE.
const HAND_HINTS = {
  A: { emoji: '✊', text: 'punho fechado, polegar ao lado' },
  B: { emoji: '✋', text: 'mão aberta, dedos juntos' },
  D: { emoji: '☝️', text: 'indicador para cima' },
  F: { emoji: '👌', text: 'polegar e indicador em círculo' },
  R: { emoji: '🤞', text: 'indicador e médio cruzados' },
  V: { emoji: '✌️', text: 'indicador e médio em V' },
  Y: { emoji: '🤙', text: 'polegar e mínimo estendidos' }
};

export function initAlphabet() {
  const input = $('#spell-input');
  const stage = $('#spell-stage');
  const count = $('#spell-count');
  const tiles = $('#spell-tiles');
  const prev = $('#spell-prev');
  const next = $('#spell-next');
  const play = $('#spell-play');
  const speed = $('#spell-speed');
  const grid = $('#alpha-grid');
  const imageBase = window.APP_CONFIG?.ALPHABET_IMAGE_BASE;

  let chars = []; // letras e espaços da palavra
  let letterPositions = []; // índices de `chars` que são letras
  let pos = 0; // posição atual dentro de letterPositions
  let timer = null;

  function showLetter(letter) {
    stage.replaceChildren();
    if (imageBase) {
      stage.append(
        el('img', {
          src: `${imageBase}/${letter}.png`,
          alt: '',
          onerror: (event) => {
            event.currentTarget.remove();
            stage.textContent = letter;
          }
        })
      );
    } else {
      const hint = HAND_HINTS[letter];
      stage.replaceChildren(
        el('span', { text: letter }),
        hint ? el('span', { class: 'hand-emoji', text: hint.emoji }) : null,
        hint ? el('span', { class: 'hand-text', text: `Mão aproximada: ${hint.text}` }) : el('span', { class: 'hand-text', text: 'Sem emoji parecido. Veja o sinal em vídeo ou com um instrutor.' })
      );
    }
  }

  function renderTiles() {
    tiles.replaceChildren(
      ...chars.map((char, index) => {
        if (char === ' ') return el('li', { class: 'tile-gap', 'aria-hidden': 'true' });
        const step = letterPositions.indexOf(index);
        return el(
          'li',
          {},
          el('button', {
            type: 'button',
            class: 'tile',
            'data-step': String(step),
            'aria-label': `Letra ${char}, ${step + 1} de ${letterPositions.length}`,
            text: char,
            onclick: () => {
              stopPlay();
              pos = step;
              update();
            }
          })
        );
      })
    );
  }

  function update() {
    const has = letterPositions.length > 0;
    prev.disabled = !has || pos === 0;
    next.disabled = !has || pos >= letterPositions.length - 1;
    play.disabled = !has;
    if (!has) {
      stage.textContent = '?';
      count.textContent = 'Digite uma palavra para começar.';
      return;
    }
    const letter = chars[letterPositions[pos]];
    showLetter(letter);
    count.textContent = `Letra ${letter}, ${pos + 1} de ${letterPositions.length}`;
    tiles.querySelectorAll('.tile').forEach((tile) => {
      if (Number(tile.dataset.step) === pos) tile.setAttribute('aria-current', 'true');
      else tile.removeAttribute('aria-current');
    });
  }

  function stopPlay() {
    clearInterval(timer);
    timer = null;
    play.setAttribute('aria-pressed', 'false');
    play.textContent = 'Reproduzir soletração';
  }

  function startPlay() {
    if (!letterPositions.length) return;
    if (pos >= letterPositions.length - 1) pos = 0;
    update();
    play.setAttribute('aria-pressed', 'true');
    play.textContent = 'Pausar';
    timer = setInterval(() => {
      if (pos >= letterPositions.length - 1) {
        stopPlay();
        return;
      }
      pos += 1;
      update();
    }, Number(speed.value));
  }

  function parse() {
    stopPlay();
    chars = [...normalize(input.value).replace(/\s+/g, ' ')].filter((c) => /[a-z ]/.test(c)).map((c) => c.toUpperCase());
    letterPositions = chars.map((c, i) => (c === ' ' ? -1 : i)).filter((i) => i >= 0);
    pos = 0;
    renderTiles();
    update();
  }

  input.addEventListener('input', debounce(parse, 150));
  $('#spell-form').addEventListener('submit', (event) => event.preventDefault());
  prev.addEventListener('click', () => {
    stopPlay();
    pos = Math.max(0, pos - 1);
    update();
  });
  next.addEventListener('click', () => {
    stopPlay();
    pos = Math.min(letterPositions.length - 1, pos + 1);
    update();
  });
  play.addEventListener('click', () => (timer ? stopPlay() : startPlay()));
  speed.addEventListener('change', () => {
    if (timer) {
      stopPlay();
      startPlay();
    }
  });

  grid.replaceChildren(
    ...LETTERS.map((letter) =>
      el(
        'li',
        {},
        el('button', {
          type: 'button',
          class: 'tile',
          'aria-label': `Mostrar a letra ${letter}`,
          text: HAND_HINTS[letter] ? `${letter} ${HAND_HINTS[letter].emoji}` : letter,
          onclick: () => {
            stopPlay();
            showLetter(letter);
            count.textContent = `Letra ${letter} do alfabeto`;
            tiles.querySelectorAll('.tile').forEach((tile) => tile.removeAttribute('aria-current'));
            stage.scrollIntoView?.({ block: 'center' });
          }
        })
      )
    )
  );

  // Vindo do dicionário: "Ver soletração"
  on('spell', (word) => {
    input.value = word;
    parse();
  });

  update();
}

import { OFFLINE_DATA } from './data.js';
import { storage, getUserId } from './storage.js';

const TIMEOUT_MS = 6000;

/**
 * Cliente da API. Se o servidor não responder, o app continua funcionando
 * com os dados de exemplo e guarda favoritos e pontuações no aparelho.
 */
export const api = {
  baseUrl: (window.APP_CONFIG && window.APP_CONFIG.API_URL) || '',
  online: false,
  userId: getUserId(),

  async request(path, { method = 'GET', body } = {}) {
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), TIMEOUT_MS);
    try {
      const response = await fetch(this.baseUrl + path, {
        method,
        signal: controller.signal,
        headers: body ? { 'Content-Type': 'application/json' } : undefined,
        body: body ? JSON.stringify(body) : undefined
      });
      if (!response.ok) {
        const error = new Error(`HTTP ${response.status}`);
        error.status = response.status;
        throw error;
      }
      this.online = true;
      return response.status === 204 ? null : await response.json();
    } catch (error) {
      if (!error.status) this.online = false; // erro de rede, não de validação
      throw error;
    } finally {
      clearTimeout(timer);
    }
  },

  async loadCatalog() {
    // Aberto como arquivo local (duplo clique) e sem API_URL: não há servidor para chamar.
    if (!this.baseUrl && location.protocol === 'file:') {
      this.online = false;
      return { ...OFFLINE_DATA, source: 'offline' };
    }
    try {
      const [categories, signs, lessons, phrases] = await Promise.all([
        this.request('/api/categories'),
        this.request('/api/signs'),
        this.request('/api/lessons'),
        this.request('/api/phrases')
      ]);
      if (![categories, signs, lessons, phrases].every(Array.isArray)) throw new Error('Resposta inesperada');
      return { categories, signs, lessons, phrases, source: 'server' };
    } catch {
      this.online = false;
      return { ...OFFLINE_DATA, source: 'offline' };
    }
  },

  async loadFavorites() {
    const local = storage.get('favorites', []);
    if (!this.online) return local;
    try {
      const remote = await this.request(`/api/users/${this.userId}/favorites`);
      const merged = [...new Set([...remote, ...local])];
      storage.set('favorites', merged);
      // envia ao servidor o que só existia no aparelho
      for (const id of local.filter((x) => !remote.includes(x))) {
        this.request(`/api/users/${this.userId}/favorites/${encodeURIComponent(id)}`, { method: 'PUT' }).catch(() => {});
      }
      return merged;
    } catch {
      return local;
    }
  },

  async setFavorite(signId, isFavorite) {
    const list = new Set(storage.get('favorites', []));
    if (isFavorite) list.add(signId);
    else list.delete(signId);
    storage.set('favorites', [...list]);
    if (!this.online) return;
    try {
      await this.request(`/api/users/${this.userId}/favorites/${encodeURIComponent(signId)}`, {
        method: isFavorite ? 'PUT' : 'DELETE'
      });
    } catch {
      /* fica salvo no aparelho e sincroniza na próxima abertura */
    }
  },

  async saveAttempt({ lessonId, score, total }) {
    const record = { lessonId, score, total, createdAt: new Date().toISOString() };
    const local = storage.get('attempts', []);
    local.push(record);
    storage.set('attempts', local.slice(-200));
    if (this.online) {
      try {
        await this.request(`/api/users/${this.userId}/attempts`, { method: 'POST', body: { lessonId, score, total } });
      } catch {
        /* mantém só no aparelho */
      }
    }
    return record;
  },

  async loadAttempts() {
    const local = [...storage.get('attempts', [])].reverse();
    if (!this.online) return local;
    try {
      const remote = await this.request(`/api/users/${this.userId}/attempts`);
      return remote.length >= local.length ? remote : local;
    } catch {
      return local;
    }
  },

  async sendFeedback({ message, contact }) {
    return this.request('/api/feedback', { method: 'POST', body: { userId: this.userId, message, contact } });
  },

  /** Apaga favoritos e pontuações no aparelho e, se possível, no servidor. */
  async deleteMyData() {
    storage.remove('favorites');
    storage.remove('attempts');
    if (!this.online) return { server: false };
    try {
      await this.request(`/api/users/${this.userId}`, { method: 'DELETE' });
      return { server: true };
    } catch {
      return { server: false };
    }
  }
};

import { $, el, formatTime } from './ui.js';

export function initCaptions() {
  const SpeechRecognitionApi = window.SpeechRecognition || window.webkitSpeechRecognition;
  const startButton = $('#cap-start');
  const langSelect = $('#cap-lang');
  const sizeRange = $('#cap-size');
  const log = $('#cap-log');
  const interim = $('#cap-interim');
  const status = $('#cap-status');
  const lines = []; // { time, text }

  const setStatus = (message) => {
    status.textContent = message;
  };

  sizeRange.addEventListener('input', () => {
    document.documentElement.style.setProperty('--caption-size', `${sizeRange.value}rem`);
  });
  document.documentElement.style.setProperty('--caption-size', `${sizeRange.value}rem`);

  function addLine(textValue) {
    const time = formatTime();
    lines.push({ time, text: textValue });
    log.append(el('p', { class: 'caption-line' }, el('time', { text: time }), textValue));
    log.scrollTop = log.scrollHeight;
  }

  const allText = () => lines.map((l) => `[${l.time}] ${l.text}`).join('\n');

  $('#cap-clear').addEventListener('click', () => {
    lines.length = 0;
    log.replaceChildren();
    interim.textContent = '';
    setStatus('Texto limpo.');
  });

  $('#cap-copy').addEventListener('click', async () => {
    if (!lines.length) {
      setStatus('Ainda não há texto para copiar.');
      return;
    }
    try {
      await navigator.clipboard.writeText(allText());
      setStatus('Texto copiado.');
    } catch {
      const area = el('textarea', { 'aria-hidden': 'true', style: 'position:fixed;opacity:0' });
      area.value = allText();
      document.body.append(area);
      area.select();
      const ok = document.execCommand?.('copy');
      area.remove();
      setStatus(ok ? 'Texto copiado.' : 'Não foi possível copiar. Selecione o texto e copie manualmente.');
    }
  });

  $('#cap-save').addEventListener('click', () => {
    if (!lines.length) {
      setStatus('Ainda não há texto para salvar.');
      return;
    }
    const blob = new Blob([allText()], { type: 'text/plain;charset=utf-8' });
    const url = URL.createObjectURL(blob);
    const link = el('a', { href: url, download: `legendas-${new Date().toISOString().slice(0, 10)}.txt` });
    document.body.append(link);
    link.click();
    link.remove();
    setTimeout(() => URL.revokeObjectURL(url), 1000);
    setStatus('Arquivo gerado.');
  });

  if (!SpeechRecognitionApi) {
    $('#cap-unsupported').hidden = false;
    startButton.disabled = true;
    setStatus('Reconhecimento de voz indisponível neste navegador.');
    return;
  }

  let recognition = null;
  let running = false;
  let restartTimer = null;

  function stop(message = 'Legendas paradas.') {
    running = false;
    clearTimeout(restartTimer);
    try {
      recognition?.stop();
    } catch {
      /* já parado */
    }
    interim.textContent = '';
    startButton.textContent = 'Iniciar legendas';
    startButton.setAttribute('aria-pressed', 'false');
    setStatus(message);
  }

  function start() {
    recognition = new SpeechRecognitionApi();
    recognition.lang = langSelect.value;
    recognition.continuous = true;
    recognition.interimResults = true;

    recognition.onstart = () => setStatus('Ouvindo. Fale perto do microfone.');
    recognition.onresult = (event) => {
      let partial = '';
      for (let i = event.resultIndex; i < event.results.length; i++) {
        const result = event.results[i];
        const piece = result[0].transcript.trim();
        if (result.isFinal) {
          if (piece) addLine(piece);
        } else {
          partial += `${piece} `;
        }
      }
      interim.textContent = partial.trim();
    };
    recognition.onerror = (event) => {
      if (event.error === 'no-speech' || event.error === 'aborted') return;
      if (event.error === 'not-allowed' || event.error === 'service-not-allowed') {
        stop('O acesso ao microfone foi negado. Libere a permissão nas configurações do navegador.');
      } else if (event.error === 'network') {
        stop('Sem conexão com o serviço de reconhecimento de voz. Verifique a internet.');
      } else {
        setStatus(`Erro no reconhecimento de voz (${event.error}).`);
      }
    };
    recognition.onend = () => {
      // O navegador encerra após silêncio; reinicia enquanto a pessoa quiser legendas.
      if (!running) return;
      restartTimer = setTimeout(() => {
        try {
          recognition.start();
        } catch {
          /* já iniciado */
        }
      }, 250);
    };

    running = true;
    startButton.textContent = 'Parar legendas';
    startButton.setAttribute('aria-pressed', 'true');
    try {
      recognition.start();
    } catch {
      stop('Não foi possível iniciar o reconhecimento de voz.');
    }
  }

  startButton.addEventListener('click', () => (running ? stop() : start()));
  langSelect.addEventListener('change', () => {
    if (running) {
      stop('Trocando o idioma…');
      start();
    }
  });
}

import { $, el, announce, openDialog, wireDialog } from './ui.js';
import { state } from './state.js';

const PHRASE_GROUPS = {
  frequentes: 'Mais usadas',
  essencial: 'Essenciais',
  saude: 'Saúde e emergência',
  cotidiano: 'Dia a dia'
};

export function initCommunicate() {
  const groups = $('#phrase-groups');
  const dialog = $('#show-dialog');
  const text = $('#show-text');
  const speakButton = $('#show-speak');
  const form = $('#custom-form');
  const custom = $('#custom-text');

  wireDialog(dialog);

  const canSpeak = 'speechSynthesis' in window && typeof SpeechSynthesisUtterance !== 'undefined';
  speakButton.hidden = !canSpeak;

  function show(message) {
    text.textContent = message;
    openDialog(dialog);
  }

  speakButton.addEventListener('click', () => {
    speechSynthesis.cancel();
    const utterance = new SpeechSynthesisUtterance(text.textContent);
    utterance.lang = 'pt-BR';
    speechSynthesis.speak(utterance);
  });
  dialog.addEventListener('close', () => {
    if (canSpeak) speechSynthesis.cancel();
  });

  form.addEventListener('submit', (event) => {
    event.preventDefault();
    const message = custom.value.trim();
    if (!message) {
      announce('Escreva uma mensagem primeiro.');
      custom.focus();
      return;
    }
    show(message);
  });

  groups.replaceChildren(
    ...Object.entries(PHRASE_GROUPS)
      .map(([key, title]) => {
        const phrases = state.phrases.filter((p) => p.category === key);
        if (!phrases.length) return null;
        return el(
          'section',
          { 'aria-labelledby': `pg-${key}` },
          el('h2', { id: `pg-${key}`, text: title }),
          el(
            'ul',
            { class: 'grid phrase-grid' },
            ...phrases.map((phrase) =>
              el(
                'li',
                {},
                el(
                  'button',
                  { type: 'button', class: `phrase-btn${phrase.urgent ? ' urgent' : ''}`, onclick: () => show(phrase.text) },
                  phrase.urgent ? el('span', { class: 'phrase-tag', text: 'Urgente' }) : null,
                  el('span', { text: phrase.text })
                )
              )
            )
          )
        );
      })
      .filter(Boolean)
  );
}

import { $, el, normalize, debounce, openDialog, closeDialog, wireDialog, safeUrl } from './ui.js';
import { state, on, emit, toggleFavorite, categoryName, signById } from './state.js';

let dictCategory = 'todos';

const favLabel = (sign, isFavorite) => (isFavorite ? `Remover ${sign.word} dos favoritos` : `Adicionar ${sign.word} aos favoritos`);

/** Botão de estrela dos cartões. */
function favIconButton(sign) {
  const isFavorite = state.favorites.has(sign.id);
  return el(
    'button',
    {
      type: 'button',
      class: 'fav-btn',
      'data-fav': sign.id,
      'aria-pressed': String(isFavorite),
      'aria-label': favLabel(sign, isFavorite),
      onclick: () => toggleFavorite(sign.id)
    },
    el('span', { 'aria-hidden': 'true', text: isFavorite ? '★' : '☆' })
  );
}

/** Botão de texto do diálogo de detalhes. */
function favTextButton(sign) {
  const isFavorite = state.favorites.has(sign.id);
  return el('button', {
    type: 'button',
    class: 'btn',
    'data-favtext': sign.id,
    'aria-pressed': String(isFavorite),
    onclick: () => toggleFavorite(sign.id),
    text: isFavorite ? '★ Nos favoritos' : '☆ Favoritar'
  });
}

/** Atualiza todos os botões de favorito visíveis. */
function syncFavButtons() {
  document.querySelectorAll('[data-fav]').forEach((button) => {
    const sign = signById(button.dataset.fav);
    if (!sign) return;
    const isFavorite = state.favorites.has(sign.id);
    button.setAttribute('aria-pressed', String(isFavorite));
    button.setAttribute('aria-label', favLabel(sign, isFavorite));
    button.firstChild.textContent = isFavorite ? '★' : '☆';
  });
  document.querySelectorAll('[data-favtext]').forEach((button) => {
    const isFavorite = state.favorites.has(button.dataset.favtext);
    button.setAttribute('aria-pressed', String(isFavorite));
    button.textContent = isFavorite ? '★ Nos favoritos' : '☆ Favoritar';
  });
}

export function signCard(sign) {
  return el(
    'li',
    { class: 'sign-card' },
    el(
      'button',
      { type: 'button', class: 'sign-open', onclick: () => openSignDialog(sign.id) },
      el('span', { class: 'sign-emoji', 'aria-hidden': 'true', text: sign.emoji ?? '' }),
      el('span', { class: 'sign-word', text: sign.word }),
      el('span', { class: 'sign-cat', text: categoryName(sign.category) })
    ),
    favIconButton(sign)
  );
}

function buildSignMedia(sign) {
  const video = safeUrl(sign.videoUrl);
  const image = safeUrl(sign.imageUrl);

  if (video) {
    const player = el('video', {
      controls: true,
      playsinline: true,
      preload: 'metadata',
      src: video,
      'aria-label': `Vídeo do sinal ${sign.word}`
    });
    const slow = el('button', {
      type: 'button',
      class: 'btn',
      'aria-pressed': 'false',
      text: 'Ver em câmera lenta',
      onclick: (event) => {
        const enable = player.playbackRate !== 0.5;
        player.playbackRate = enable ? 0.5 : 1;
        event.currentTarget.setAttribute('aria-pressed', String(enable));
        event.currentTarget.textContent = enable ? 'Câmera lenta ligada' : 'Ver em câmera lenta';
      }
    });
    return el('div', { class: 'sign-media' }, player, slow);
  }
  if (image) {
    return el('div', { class: 'sign-media' }, el('img', { src: image, alt: `Sinal de ${sign.word} em Libras` }));
  }
  return el(
    'div',
    { class: 'sign-media' },
    el('span', { class: 'big', 'aria-hidden': 'true', text: sign.emoji ?? '' }),
    el('p', { class: 'muted', text: 'O vídeo deste sinal ainda não foi adicionado.' })
  );
}

export function openSignDialog(id) {
  const sign = signById(id);
  if (!sign) return;
  const dialog = $('#sign-dialog');
  $('#sign-title').textContent = sign.word;

  $('#sign-body').replaceChildren(
    buildSignMedia(sign),
    el('p', {}, el('span', { class: `badge ${sign.validated ? 'ok' : 'warn'}`, text: sign.validated ? 'Revisado por intérprete' : 'Exemplo, ainda sem revisão' })),
    el('h3', { text: 'Como fazer' }),
    el('p', { text: sign.description }),
    sign.tip ? el('p', { class: 'muted', text: `Dica: ${sign.tip}` }) : null,
    el('p', { class: 'muted', text: `Categoria: ${categoryName(sign.category)}` }),
    el(
      'div',
      { class: 'btn-row' },
      favTextButton(sign),
      el('button', {
        type: 'button',
        class: 'btn',
        text: 'Ver soletração',
        onclick: () => {
          closeDialog(dialog);
          emit('spell', sign.word);
          location.hash = '#alfabeto';
        }
      })
    )
  );
  openDialog(dialog);
}

export function initDictionary() {
  const input = $('#dict-search');
  const chips = $('#dict-chips');
  const grid = $('#dict-grid');
  const status = $('#dict-status');
  const empty = $('#dict-empty');

  wireDialog($('#sign-dialog'));

  const filters = [{ id: 'todos', name: 'Todos' }, { id: 'favoritos', name: 'Favoritos' }, ...state.categories];
  chips.replaceChildren(
    ...filters.map((filter) =>
      el('button', {
        type: 'button',
        class: 'chip-btn',
        'data-filter': filter.id,
        'aria-pressed': String(filter.id === dictCategory),
        text: filter.name,
        onclick: () => {
          dictCategory = filter.id;
          chips.querySelectorAll('button').forEach((b) => b.setAttribute('aria-pressed', String(b.dataset.filter === dictCategory)));
          render();
        }
      })
    )
  );

  function matches(sign) {
    if (dictCategory === 'favoritos' && !state.favorites.has(sign.id)) return false;
    if (dictCategory !== 'todos' && dictCategory !== 'favoritos' && sign.category !== dictCategory) return false;
    const term = normalize(input.value);
    return !term || normalize(`${sign.word} ${sign.description} ${categoryName(sign.category)}`).includes(term);
  }

  function render() {
    const list = state.signs.filter(matches).sort((a, b) => a.word.localeCompare(b.word, 'pt-BR'));
    grid.replaceChildren(...list.map(signCard));
    empty.hidden = list.length > 0;
    status.textContent = list.length === 1 ? '1 sinal encontrado' : `${list.length} sinais encontrados`;
  }

  input.addEventListener('input', debounce(render, 200));
  on('favorites', () => {
    syncFavButtons();
    if (dictCategory === 'favoritos') {
      render();
      input.focus();
    }
  });
  render();
}

import { $, el, shuffle, announce } from './ui.js';
import { state, on, emit, signById } from './state.js';
import { api } from './api.js';

export function initLearn() {
  const list = $('#lesson-list');
  const panel = $('#lessons-panel');
  const quizEl = $('#quiz');
  let quiz = null; // { lesson, questions, index, score }

  function bestFor(lessonId) {
    const tries = state.attempts.filter((a) => a.lessonId === lessonId);
    if (!tries.length) return null;
    return tries.reduce((best, a) => (a.score / a.total > best.score / best.total ? a : best));
  }

  function renderLessons() {
    list.replaceChildren(
      ...state.lessons.map((lesson) => {
        const best = bestFor(lesson.id);
        return el(
          'li',
          { class: 'lesson-card' },
          el('h2', { text: lesson.title }),
          el('p', { text: lesson.description }),
          el(
            'p',
            {},
            el('span', { class: 'badge', text: `${lesson.signIds.length} sinais` }),
            ' ',
            best
              ? el('span', { class: 'badge ok', text: `Melhor: ${best.score} de ${best.total}` })
              : el('span', { class: 'badge', text: 'Ainda não praticada' })
          ),
          el('button', {
            type: 'button',
            class: 'btn btn-primary',
            'aria-label': `${best ? 'Praticar de novo' : 'Começar'} a lição ${lesson.title}`,
            text: best ? 'Praticar de novo' : 'Começar',
            onclick: () => startLesson(lesson)
          })
        );
      })
    );
  }

  function buildQuestions(lesson) {
    const lessonSigns = lesson.signIds.map(signById).filter(Boolean);
    return shuffle(lessonSigns).map((sign) => {
      const others = shuffle(state.signs.filter((s) => s.id !== sign.id));
      const distractors = [...others.filter((s) => s.category === sign.category), ...others.filter((s) => s.category !== sign.category)].slice(0, 3);
      return { sign, options: shuffle([sign, ...distractors]) };
    });
  }

  function showQuiz(show) {
    panel.hidden = show;
    quizEl.hidden = !show;
  }

  function backToLessons() {
    quiz = null;
    renderLessons();
    showQuiz(false);
    $('#h-apr').focus();
  }

  function startLesson(lesson) {
    const questions = buildQuestions(lesson);
    if (questions.length === 0) return;
    quiz = { lesson, questions, index: 0, score: 0 };
    showQuiz(true);
    renderQuestion();
  }

  function renderQuestion() {
    const question = quiz.questions[quiz.index];
    const total = quiz.questions.length;

    const legend = el('legend', { tabindex: '-1', text: `Pergunta ${quiz.index + 1} de ${total}: qual palavra combina com esta descrição?` });
    const feedback = el('p', { class: 'feedback', role: 'status' });
    const submit = el('button', { type: 'submit', class: 'btn btn-primary', text: 'Responder' });

    const options = el(
      'div',
      { class: 'options' },
      ...question.options.map((option) =>
        el(
          'label',
          { class: 'option', dataset: { id: option.id } },
          el('input', { type: 'radio', name: 'answer', value: option.id }),
          el('span', { text: option.word }),
          el('span', { class: 'mark', 'aria-hidden': 'true' })
        )
      )
    );

    const form = el(
      'form',
      { class: 'quiz-box', novalidate: true },
      el('fieldset', {}, legend, el('p', { class: 'prompt', text: question.sign.description }), options),
      feedback,
      el('div', { class: 'btn-row' }, submit, el('button', { type: 'button', class: 'btn', text: 'Sair da lição', onclick: backToLessons }))
    );

    form.addEventListener('submit', (event) => {
      event.preventDefault();
      const chosen = form.querySelector('input[name="answer"]:checked');
      if (!chosen) {
        feedback.textContent = 'Escolha uma opção antes de responder.';
        return;
      }
      const correct = chosen.value === question.sign.id;
      if (correct) quiz.score += 1;

      form.querySelectorAll('.option').forEach((label) => {
        label.querySelector('input').disabled = true;
        const mark = label.querySelector('.mark');
        if (label.dataset.id === question.sign.id) {
          label.classList.add('correct');
          mark.textContent = '✔ Correta';
        } else if (label.dataset.id === chosen.value) {
          label.classList.add('wrong');
          mark.textContent = '✖ Sua resposta';
        }
      });
      feedback.textContent = correct ? 'Correto! Muito bem.' : `Quase. A resposta certa é “${question.sign.word}”.`;

      const isLast = quiz.index === total - 1;
      const nextButton = el('button', {
        type: 'button',
        class: 'btn btn-primary',
        text: isLast ? 'Ver resultado' : 'Próxima pergunta',
        onclick: () => {
          quiz.index += 1;
          if (isLast) finishQuiz();
          else renderQuestion();
        }
      });
      submit.replaceWith(nextButton);
      nextButton.focus();
    });

    quizEl.replaceChildren(
      el('div', { class: 'quiz-head' }, el('h2', { text: quiz.lesson.title }), el('p', { class: 'muted', text: `Acertos até agora: ${quiz.score}` })),
      form
    );
    legend.focus();
  }

  async function finishQuiz() {
    const { lesson, score, questions } = quiz;
    const total = questions.length;
    const record = await api.saveAttempt({ lessonId: lesson.id, score, total });
    state.attempts.unshift(record);
    emit('progress');

    const ratio = score / total;
    const message =
      ratio === 1
        ? 'Perfeito! Você acertou todas.'
        : ratio >= 0.6
          ? 'Bom trabalho! Revise os sinais que errou e tente de novo.'
          : 'Continue praticando. Abra o dicionário para rever os sinais desta lição.';

    quizEl.replaceChildren(
      el(
        'div',
        { class: 'quiz-box' },
        el('h2', { id: 'quiz-result', tabindex: '-1', text: `Resultado: ${lesson.title}` }),
        el('p', { class: 'result-score', text: `${score} de ${total}` }),
        el('p', { text: message }),
        el(
          'div',
          { class: 'btn-row' },
          el('button', { type: 'button', class: 'btn btn-primary', text: 'Tentar de novo', onclick: () => startLesson(lesson) }),
          el('button', { type: 'button', class: 'btn', text: 'Voltar às lições', onclick: backToLessons })
        )
      )
    );
    $('#quiz-result').focus();
    announce(`Lição concluída: ${score} de ${total}.`);
  }

  on('progress', renderLessons);
  renderLessons();
}

import { $, el } from './ui.js';
import { state, on, emit, signById } from './state.js';
import { api } from './api.js';
import { signCard } from './dictionary.js';

export function initProgress() {
  const stats = $('#stats');
  const favList = $('#fav-list');
  const favEmpty = $('#fav-empty');
  const rows = $('#attempt-rows');

  const stat = (label, value) => el('div', { class: 'stat' }, el('dt', { text: label }), el('dd', { text: String(value) }));

  function bestOf(lessonId) {
    const tries = state.attempts.filter((a) => a.lessonId === lessonId);
    if (!tries.length) return { best: null, count: 0 };
    return { best: tries.reduce((b, a) => (a.score / a.total > b.score / b.total ? a : b)), count: tries.length };
  }

  function render() {
    const summaries = state.lessons.map((lesson) => ({ lesson, ...bestOf(lesson.id) }));
    const practiced = summaries.filter((s) => s.best);
    const average = practiced.length ? Math.round((practiced.reduce((sum, s) => sum + s.best.score / s.best.total, 0) / practiced.length) * 100) : null;

    stats.replaceChildren(
      stat('Sinais favoritos', state.favorites.size),
      stat('Lições praticadas', `${practiced.length} de ${state.lessons.length}`),
      stat('Média das melhores notas', average === null ? '—' : `${average}%`),
      stat('Tentativas', state.attempts.length)
    );

    const favorites = [...state.favorites].map(signById).filter(Boolean).sort((a, b) => a.word.localeCompare(b.word, 'pt-BR'));
    favList.replaceChildren(...favorites.map(signCard));
    favEmpty.hidden = favorites.length > 0;

    rows.replaceChildren(
      ...summaries.map(({ lesson, best, count }) =>
        el('tr', {}, el('th', { scope: 'row', text: lesson.title }), el('td', { text: best ? `${best.score} de ${best.total}` : '—' }), el('td', { text: String(count) }))
      )
    );
  }

  on('progress', render);
  on('favorites', render);
  render();

  // Sugestões
  const form = $('#feedback-form');
  const message = $('#fb-message');
  const contact = $('#fb-contact');
  const fbStatus = $('#fb-status');
  const setFbStatus = (text, kind) => {
    fbStatus.textContent = text;
    fbStatus.className = `form-status${kind ? ` is-${kind}` : ''}`;
  };

  form.addEventListener('submit', async (event) => {
    event.preventDefault();
    const text = message.value.trim();
    if (text.length < 3) {
      setFbStatus('Escreva uma mensagem com pelo menos 3 letras.', 'error');
      message.focus();
      return;
    }
    const submit = form.querySelector('button[type="submit"]');
    submit.disabled = true;
    try {
      await api.sendFeedback({ message: text, contact: contact.value.trim() || undefined });
      setFbStatus('Obrigado! Sua mensagem foi enviada.', 'ok');
      form.reset();
    } catch {
      setFbStatus('Não foi possível enviar agora. Verifique a conexão com o servidor e tente de novo.', 'error');
    } finally {
      submit.disabled = false;
    }
  });

  // Apagar dados (confirmação em dois toques, sem janelas do navegador)
  const reset = $('#reset-data');
  const resetStatus = $('#reset-status');
  let armed = null;
  reset.addEventListener('click', async () => {
    if (!armed) {
      reset.textContent = 'Toque de novo para confirmar';
      armed = setTimeout(() => {
        armed = null;
        reset.textContent = 'Apagar meus dados';
      }, 5000);
      return;
    }
    clearTimeout(armed);
    armed = null;
    reset.textContent = 'Apagar meus dados';
    const { server } = await api.deleteMyData();
    state.favorites = new Set();
    state.attempts = [];
    emit('favorites', {});
    emit('progress');
    resetStatus.className = 'form-status is-ok';
    resetStatus.textContent = server ? 'Seus dados foram apagados neste aparelho e no servidor.' : 'Seus dados foram apagados neste aparelho. Não foi possível apagar no servidor agora.';
  });
}

  $$('[data-view]').forEach((section) => {

    announce(`Página ${VIEWS[view]}`);
  }
  firstNavigation = false;
  emit('route', view);
}

}

import { $, el, formatTime, vibrate, prefersReducedMotion } from './ui.js';

let toastTimer;

/** Aviso visual grande, tela piscando (suave) e vibração. */
export function fireAlert(message) {
  const toast = $('#alert-toast');
  toast.textContent = message;
  toast.hidden = false;
  clearTimeout(toastTimer);
  toastTimer = setTimeout(() => {
    toast.hidden = true;
  }, 7000);

  const flash = $('#flash');
  if (!prefersReducedMotion() && document.documentElement.dataset.flash !== 'off') {
    flash.classList.remove('on');
    void flash.offsetWidth; // reinicia a animação
    flash.classList.add('on');
  }
  vibrate([300, 120, 300, 120, 300]);
}

export function initSoundAlert() {
  const startButton = $('#snd-start');
  const testButton = $('#snd-test');
  const range = $('#snd-threshold');
  const rangeOut = $('#snd-threshold-out');
  const meter = $('#snd-meter');
  const fill = $('#snd-fill');
  const mark = $('#snd-mark');
  const status = $('#snd-status');
  const history = $('#snd-history');
  const chip = $('#alert-chip');

  let stream = null;
  let audioContext = null;
  let analyser = null;
  let samples = null;
  let timer = null;
  let lastFire = 0;
  let lastAria = 0;
  let eventCount = 0;
  let threshold = Number(range.value);

  const setStatus = (message) => {
    status.textContent = message;
  };

  function syncThreshold() {
    threshold = Number(range.value);
    mark.style.left = `${threshold}%`;
    rangeOut.textContent = `${threshold}%`;
  }
  syncThreshold();
  range.addEventListener('input', syncThreshold);

  $('#flash').addEventListener('animationend', (event) => event.currentTarget.classList.remove('on'));

  function addHistory(message) {
    if (eventCount === 0) history.replaceChildren();
    eventCount += 1;
    history.prepend(el('li', { text: `${formatTime()}: ${message}` }));
    while (history.children.length > 20) history.lastChild.remove();
  }

  function sample() {
    analyser.getByteTimeDomainData(samples);
    let sum = 0;
    for (let i = 0; i < samples.length; i++) {
      const v = (samples[i] - 128) / 128;
      sum += v * v;
    }
    const rms = Math.sqrt(sum / samples.length);
    const db = 20 * Math.log10(Math.max(rms, 1e-5));
    const level = Math.max(0, Math.min(100, Math.round(((db + 60) / 60) * 100))); // -60 dB = 0%, 0 dB = 100%
    fill.style.width = `${level}%`;

    const now = Date.now();
    if (now - lastAria > 500) {
      meter.setAttribute('aria-valuenow', String(level));
      lastAria = now;
    }
    if (level >= threshold && now - lastFire > 3000) {
      lastFire = now;
      const message = `Som alto detectado às ${formatTime()}`;
      fireAlert(message);
      addHistory('som alto detectado.');
    }
  }

  async function start() {
    if (!navigator.mediaDevices?.getUserMedia) {
      setStatus('Este navegador não permite usar o microfone. No celular, abra o app por uma conexão segura (https).');
      return;
    }
    try {
      stream = await navigator.mediaDevices.getUserMedia({
        audio: { echoCancellation: false, noiseSuppression: false, autoGainControl: false }
      });
    } catch (error) {
      setStatus(
        error?.name === 'NotAllowedError'
          ? 'O acesso ao microfone foi negado. Libere a permissão nas configurações do navegador.'
          : 'Não foi possível acessar o microfone.'
      );
      return;
    }
    const AudioContextApi = window.AudioContext || window.webkitAudioContext;
    audioContext = new AudioContextApi();
    if (audioContext.state === 'suspended') await audioContext.resume();
    analyser = audioContext.createAnalyser();
    analyser.fftSize = 1024;
    audioContext.createMediaStreamSource(stream).connect(analyser);
    samples = new Uint8Array(analyser.fftSize);

    timer = setInterval(sample, 100);
    startButton.textContent = 'Desativar alerta';
    startButton.setAttribute('aria-pressed', 'true');
    chip.hidden = false;
    setStatus('Alerta ativo. Mantenha esta página aberta e a tela ligada.');
  }

  function stop() {
    clearInterval(timer);
    timer = null;
    stream?.getTracks().forEach((track) => track.stop());
    audioContext?.close?.();
    stream = null;
    audioContext = null;
    fill.style.width = '0%';
    meter.setAttribute('aria-valuenow', '0');
    startButton.textContent = 'Ativar alerta';
    startButton.setAttribute('aria-pressed', 'false');
    chip.hidden = true;
    setStatus('O alerta está desligado.');
  }

  startButton.addEventListener('click', () => (timer ? stop() : start()));
  testButton.addEventListener('click', () => {
    fireAlert('Teste: assim será o aviso de som.');
    addHistory('teste do aviso.');
  });
}

// Armazenamento local seguro: se o navegador bloquear o localStorage, usa a memória.
const mem = new Map();
const PREFIX = 'libras-acesso:';

export const storage = {
  get(key, fallback = null) {
    try {
      const raw = localStorage.getItem(PREFIX + key);
      if (raw !== null) return JSON.parse(raw);
    } catch {
      /* armazenamento indisponível */
    }
    return mem.has(key) ? mem.get(key) : fallback;
  },
  set(key, value) {
    mem.set(key, value);
    try {
      localStorage.setItem(PREFIX + key, JSON.stringify(value));
    } catch {
      /* armazenamento indisponível */
    }
  },
  remove(key) {
    mem.delete(key);
    try {
      localStorage.removeItem(PREFIX + key);
    } catch {
      /* armazenamento indisponível */
    }
  }
};

/** Código anônimo deste aparelho (não identifica a pessoa). */
export function getUserId() {
  let id = storage.get('userId');
  if (!id) {
    id = crypto.randomUUID ? crypto.randomUUID() : `u-${Math.random().toString(16).slice(2)}${Date.now().toString(16)}`;
    storage.set('userId', id);
  }
  return id;
}

// Utilitários de interface.
export const $ = (selector, root = document) => root.querySelector(selector);
export const $$ = (selector, root = document) => [...root.querySelectorAll(selector)];

/** Cria um elemento. Textos entram como texto (nunca como HTML), o que evita XSS. */
export function el(tag, attrs = {}, ...children) {
  const node = document.createElement(tag);
  for (const [key, value] of Object.entries(attrs)) {
    if (value === false || value == null) continue;
    if (key === 'class') node.className = value;
    else if (key === 'text') node.textContent = value;
    else if (key === 'dataset') Object.assign(node.dataset, value);
    else if (key.startsWith('on') && typeof value === 'function') node.addEventListener(key.slice(2).toLowerCase(), value);
    else node.setAttribute(key, value === true ? '' : value);
  }
  for (const child of children.flat()) {
    if (child == null || child === false) continue;
    node.append(child.nodeType ? child : document.createTextNode(String(child)));
  }
  return node;
}

let liveTimer;
/** Anuncia uma mensagem para leitores de tela. */
export function announce(message, { assertive = false } = {}) {
  const region = $(assertive ? '#live-assertive' : '#live-polite');
  if (!region) return;
  clearTimeout(liveTimer);
  region.textContent = '';
  liveTimer = setTimeout(() => {
    region.textContent = message;
  }, 60);
}

/** Minúsculas e sem acentos, para busca. */
export function normalize(text) {
  return String(text ?? '')
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .trim();
}

export function formatTime(date = new Date()) {
  return date.toLocaleTimeString('pt-BR', { hour: '2-digit', minute: '2-digit', second: '2-digit' });
}

export function debounce(fn, ms = 200) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

export function shuffle(list) {
  const copy = [...list];
  for (let i = copy.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copy[i], copy[j]] = [copy[j], copy[i]];
  }
  return copy;
}

export function prefersReducedMotion() {
  return document.documentElement.dataset.motion === 'reduce' || window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}

export function vibrate(pattern) {
  if (document.documentElement.dataset.vibrate === 'off') return;
  try {
    navigator.vibrate?.(pattern);
  } catch {
    /* vibração indisponível */
  }
}

/** Aceita só endereços http(s) ou relativos. Evita "javascript:" vindo do banco de dados. */
export function safeUrl(url) {
  return typeof url === 'string' && /^(https?:\/\/|\/(?!\/))/i.test(url) ? url : null;
}

export function openDialog(dialog) {
  if (typeof dialog.showModal === 'function') {
    if (!dialog.open) dialog.showModal();
  } else {
    dialog.setAttribute('open', '');
  }
}

export function closeDialog(dialog) {
  if (typeof dialog.close === 'function') dialog.close();
  else dialog.removeAttribute('open');
}

/** Liga os botões [data-close] e o clique no fundo ao fechamento do diálogo. */
export function wireDialog(dialog) {
  dialog.addEventListener('click', (event) => {
    if (event.target === dialog) closeDialog(dialog);
  });
  dialog.querySelectorAll('[data-close]').forEach((button) => button.addEventListener('click', () => closeDialog(dialog)));
}
